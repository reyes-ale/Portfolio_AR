# Videos de proyectos

Coloca aquí un clip corto (10–20s), en loop y sin audio, de cada proyecto con estos nombres exactos (o cambia las rutas en `src/data/projects.js`):

| Archivo                     | Proyecto                        |
|------------------------------|----------------------------------|
| `colmena.mp4`                | Colmena                         |
| `besteamhn-landing.mp4`      | BeSteamHN landing page          |
| `ai-tutor.mp4`               | BeSteamHN AI Tutor              |
| `workshops.mp4`              | Introduction to the Digital Era |
| `la-oficina.mp4`             | La Oficina restaurant           |

Recomendado: MP4 (H.264), sin audio, unos 5–10 MB, relación 16:10 o similar.

Si un archivo no existe, la tarjeta muestra un marcador con el nombre del archivo esperado, así que puedes ir agregándolos de a poco.
